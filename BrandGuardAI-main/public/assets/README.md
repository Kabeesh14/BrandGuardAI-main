# BrandGuard AI — Asset Folder

Place your BrandGuard AI logo files directly into this folder:

1. `logo.png`
   - Location: `BrandGuardAI-main/BrandGuardAI-main/public/assets/logo.png`
   - Usage: Application Sidebar logo and high-resolution icons.
   - Recommended: Square or transparent PNG, preserving your purple-blue-cyan design.

2. `favicon.png`
   - Location: `BrandGuardAI-main/BrandGuardAI-main/public/assets/favicon.png`
   - Usage: Browser tab favicon (32x32 or 64x64 transparent PNG).
   - Note: If `favicon.png` is not provided, the browser also falls back to `logo.png`.
